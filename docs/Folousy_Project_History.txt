1. Product
Arabic RTL personal money notebook. Default vertically stacked funds: صدقة10%, الادخار30%, المصاريف60%. Charity percentage can increase/decrease according to ability; all configured percentages total100%. Support3–12 funds with editable name, color, order and motto. Four distinct light/dark themes. Fast amount entry, optional note, calendar date and repeated Enter.

2. Accounting invariants
EGP values use integer piastres. Income records capture their original rates/allocations; configuration changes affect future income. Internal transfers conserve total money. External charity is separate from personal income/balances. Monthly gross additions, carryover and remaining are distinct. New expenses cannot create negative dated balances: offer explicit coverage from another sufficiently funded fund, then commit transfer+expense atomically. Legacy transactions remain readable without silent rewrites.

3. Current stack
React19, TypeScript, App Router structure, Vinext/Vite, Cloudflare Workers and D1 SQLite. Hosted identity is platform ChatGPT auth. This is not a conventional next start deployment. Guest mode is device-local. A separate Supabase project is ready; persistence migration and direct Google OAuth are pending, not completed.

4. Persistence
lib/sync-queue.ts provides durable account-scoped local pending snapshots and serialized background CAS writes.
